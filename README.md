Every story carries its outlet (Reuters, AFP, AP, NPR, the New York Times, the Wall Street Journal, the Justice Department, LRT, Fortune, FDNY) so a reader can verify it.

This is v2 of the entry: v1 was a 7-story narrative (1,967 characters) and sat at #988 in the dev-phase leaderboard. The leaderboard's top 10 all run 14–15 short sourced stories at nearly the full 2,000-character budget, ordered by consequence — so v2 follows exactly that winning pattern, in the house's own best-calibrated format: a numbered list, most important first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `summary.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), byte for byte, UTF-8, 1,991 characters — inside the 1–2,000 gate. Two runs write identical bytes.
